# LAB-001 — Perfil de usuario

## 1. Objetivo del laboratorio

Desarrollar un programa básico en JavaScript que permita representar la información de un usuario mediante variables y mostrarla en la consola.

El laboratorio tiene como propósito practicar la declaración de variables, identificar tipos de datos y comprender cómo modificar valores durante la ejecución de un programa.

## 2. Conceptos aprendidos

Durante este laboratorio se trabajaron los siguientes conceptos:

- **Declaración de variables:** uso de `const` y `let` según la necesidad de reasignar valores.
- **Tipos de datos primitivos:** `string`, `number` y `boolean`.
- **Salida por consola:** utilización de `console.log()` para mostrar información.
- **Template literals:** interpolación de variables mediante `${}`.
- **Reasignación de variables:** modificación del valor de una variable declarada con `let`.
- **Operaciones aritméticas:** suma de valores numéricos.
- **Operador `typeof`:** identificación del tipo de dato almacenado en una variable.
