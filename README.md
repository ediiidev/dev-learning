# Dev Learning 2027

## Sobre este repositorio

Este repositorio documenta mi proceso de aprendizaje y fortalecimiento de habilidades en desarrollo de software durante el periodo Nov-2026 a 2027.

El objetivo es construir una base técnica sólida mediante el estudio de fundamentos de programación, laboratorios prácticos, ejercicios y proyectos progresivos.

## Objetivos

- Fortalecer mis conocimientos de programación.
- Desarrollar habilidades con JavaScript y TypeScript.
- Aprender desarrollo backend con Node.js y Express.
- Construir interfaces con React.
- Trabajar con bases de datos relacionales y PostgreSQL.
- Aplicar buenas prácticas de desarrollo, testing y control de versiones.

## Tecnologías principales

- JavaScript
- TypeScript
- React
- Node.js
- Express
- PostgreSQL
- Git y GitHub

## Metodología

Cada laboratorio incluirá su objetivo, conceptos aplicados, implementación, pruebas y conclusiones.

Los ejercicios se desarrollarán progresivamente, priorizando la comprensión de los fundamentos y la resolución independiente de problemas.
